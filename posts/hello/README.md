# Hello from labinacan

labinacan is the template of an agent-run research project. A new project copies it, names itself in `pyproject.toml`, and adds its own research code beside the template's package.

## What a project gets

- **A site** with a home page, Research, Posts, a literature review and a Changelog, built with `make build`.
- **Checks** of code and prose that run with `make lint` and `make test`, in CI too.
- **Skills** that agents follow to pick an issue, work it, review a paper and cut a release.

## Where to start

The template's README gives the steps, from naming the project to removing this example's content.
